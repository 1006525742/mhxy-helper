# 抓鬼识别模块

## 识别流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     前端 (Vue 3 + TypeScript)                    │
├─────────────────────────────────────────────────────────────────┤
│  1. 屏幕共享 (getDisplayMedia)                                   │
│     ↓ 获取游戏画面                                               │
│                                                                 │
│  2. YOLO 检测 (TensorFlow.js)                                    │
│     ↓ 检测 任务追踪(类0) + 钟馗(类1)                              │
│     ↓ 置信度 > 0.8                                               │
│                                                                 │
│  3. 点击"手动识别"按钮                                           │
│     ↓ 裁剪区域：任务追踪 bbox 底部                                │
│     ↓ 尺寸: (bbox.w+10) × (bbox.h×4, 限制100-280px)              │
│                                                                 │
│  4. POST 到后端 API                                              │
│     https://api.mhwk.cloud/api/ghost/capture                    │
│     ↓ base64 PNG 图片                                            │
└───────────────────────┬─────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────────────┐
│                     后端 (FastAPI + Python)                      │
├─────────────────────────────────────────────────────────────────┤
│  5. OCR 识别 (PP-OCRv6_small)                                    │
│     ↓ 直接识别原图（不提取黄色文字）                              │
│     ↓ 字典: combined_dict.txt (41字符)                           │
│                                                                 │
│  6. 鲁棒解析器                                                   │
│     ├─ 模式1: 数字+逗号+数字 (61,19)                             │
│     ├─ 模式2: 数字+加号+数字 (108+125)                           │
│     ├─ 模式3: 无分隔符数字串 (6119 → 61,19)                      │
│     ↓ 提取坐标 (x, y)                                            │
│                                                                 │
│  7. 地图名匹配                                                   │
│     ├─ 关键词匹配: 傲来国、女儿村、五庄观...                      │
│     ├─ OCR 误识别纠正: 安儿村→女儿村, 天唐→大唐                   │
│     ↓                                                            │
│     └─ 地图名未识别 + 坐标识别成功？                              │
│        ↓ 是                                                      │
│        调用地名识别模型兜底 (PP-OCRv5 place.onnx)                 │
│                                                                 │
│  8. 抓鬼预测 (GhostPredictor)                                    │
│     ↓ 根据地图名+坐标计算小鬼位置                                 │
│     ↓ 返回: 象限区域、角落优先区域、标注地图                      │
│                                                                 │
│  9. 返回结果                                                     │
│     ├─ success: true/false                                       │
│     ├─ map: 地图名                                               │
│     ├─ x, y: 坐标                                                │
│     ├─ position_areas: ["西南象限"]                              │
│     ├─ corner_areas: ["左下角优先"]                              │
│     └─ annotated_image: 标注地图图片 (base64)                    │
└─────────────────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────────────┐
│                     前端显示                                     │
├─────────────────────────────────────────────────────────────────┤
│  10. 显示识别结果                                                │
│      ├─ 地图名                                                   │
│      ├─ 坐标                                                     │
│      ├─ 预测区域                                                 │
│      └─ 标注地图（右侧/画中画）                                   │
│                                                                 │
│  11. 画中画功能 (Picture-in-Picture API)                         │
│      ├─ Canvas 绘制地图                                          │
│      ├─ MediaStream → Video                                      │
│      └─ requestPictureInPicture()                                │
│      ↓ 浏览器独立窗口显示                                         │
└─────────────────────────────────────────────────────────────────┘
```

## 配置

### YOLO 模型

| 参数 | 值 |
|------|-----|
| 模型 | TensorFlow.js GraphModel |
| 输入 | 480×480×3 (归一化到 0-1) |
| 输出 | 12×4725 (4 bbox + 8 类置信度) |
| 置信度阈值 | 0.8 |
| 监控间隔 | 200ms |

### 检测类别

| ID | 名称 | 用途 |
|----|------|------|
| 0 | 任务追踪 | 定位裁剪区域 |
| 1 | 钟馗 | 触发抓鬼模式 |
| 2 | 黑无常 | 触发抓鬼模式 |
| 3 | 店小二 | 触发打图模式 |
| 4 | 接引仙女 | - |
| 5 | 左侧干扰 | - |
| 6 | 驿站老板 | - |
| 7 | 强盗对话 | - |

### OCR 配置

| 参数 | 值 |
|------|-----|
| 模型 | PP-OCRv6_small (det + rec) |
| 字典 | combined_dict.txt (41字符) |
| 输入 | 原图（不提取黄色文字） |

### 地名识别兜底模型

| 参数 | 值 |
|------|-----|
| 模型 | PP-OCRv5 训练的 place.onnx |
| 准确率 | 99.99% (验证集) |
| 触发条件 | 地图名未识别 + 坐标识别成功 |

### 字典内容 (combined_dict.txt)

```

# 分隔符

# 地名关键字

```

## 鲁棒解析器

### 支持的坐标格式

| OCR 输出 | 解析结果 |
|---------|---------|
| `建邺城61,19` | 地图=建邺城, x=61, y=19 ✓ |
| `建邺城6119` | 地图=建邺城, x=61, y=19 ✓ (逗号丢失) |
| `长寿村108+125` | 地图=长寿村, x=108, y=125 ✓ (坐标被拆分) |
| `朱紫国9973` | 地图=朱紫国, x=99, y=73 ✓ (逗号丢失) |

### 解析优先级

1. 数字+逗号+数字 (正常格式)
2. 数字+加号+数字 (坐标被拆分)
3. 无分隔符数字串 (逗号丢失，智能切分)

## API

### POST /api/ghost/capture

请求：
```json
{
  "image": "base64编码的图片"
}
```

响应：
```json
{
  "success": true,
  "map": "西梁女国",
  "x": 91,
  "y": 70,
  "position_areas": ["西南象限"],
  "corner_areas": ["左下角优先"],
  "confidence": 0.95,
  "annotated_image": "base64",
  "ocr": {
    "map": "西梁女国",
    "x": 91,
    "y": 70,
    "time_ms": 290.3
  }
}
```

## 画中画功能

使用浏览器原生 Picture-in-Picture API：

```javascript
// Canvas 绘制地图 → MediaStream → Video → PiP
canvas.captureStream(8)  // 8fps
pipVideo.srcObject = stream
pipVideo.requestPictureInPicture()
```

特点：
- 浏览器最小化后继续显示
- 独立窗口，始终置顶
- 每 120ms 重绘更新内容
