## 四、关键洞察：缺的不是图标，是 catalog 登记

现有 **82 个图标**覆盖的物品远多于 catalog 登记的 169 项。例如：
- `五宝/` 有 5 个图标（夜光珠 定魂珠 避水珠 金刚石 龙鳞），但 catalog **完全没登记**
- `道具/` 有 48 个图标，大量（分解符/符石卷轴/海马/强化石/修炼果/树苗/清灵仙露/乐器/花…）未登记
- `高级兽决/高级魔兽要诀.png`、`道具/高级召唤兽内丹.png` 早就在库，却分别只有 1 个占位名

> 与「特赦令牌」那次完全同源：PNG 在 `public/static/icons/<分类>/`，但 `wuji_catalog.json` 没记该物品名 → 前端查不到 → 不显示 / 识别不到。

## 五、补录方法（零代码，改 JSON 即可）

在 `backend/data/wuji_catalog.json` 加条目，格式：
```json
"光芒石": { "icon": "宝石/光芒石.png", "category": "宝石" },
"高级必杀": { "icon": "高级兽决/高级魔兽要诀.png", "category": "高级兽决" }
```
改完 `launchctl kickstart -k gui/$(id -u)/com.mhxy.harvest` 重启后端生效。

⚠️ 注意：物品名清单需与游戏实际名称完全一致，补录前应核对（尤其高级兽决/高级内丹全表）。
